# SKYFORGE Game Design

## Core loop
CONNECT WALLET → DEPLOY → FIGHT → SCORE → LOOT → UPGRADE → TRADE → COMPETE

## First mission
**Operation Dustfall** — a desert combat zone with enemy drones and ground targets.

## Helicopter
Initial prototype: AH-9 Viper.

Planned stats:
- Armor
- Speed
- Handling
- Firepower
- Fuel
- Radar
- Missile capacity

## Weapons
Initial:
- machine gun
- rockets

Planned:
- missiles
- EMP
- heavy cannon
- classified weapons

## Economy
- WAR SCORE: non-transferable progression/competition score
- Energy/Fuel: gameplay resource
- $SKY: ecosystem token and access asset
- NFTs: meaningful player-owned assets

## Access
Wallet must hold at least 20,000 $SKY for full game access.

## Marketplace
Players will eventually list helicopters, weapons, blueprints and selected resources.

## Design rule
The game must remain fun without requiring a blockchain transaction for normal combat.
