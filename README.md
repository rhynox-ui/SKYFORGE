# SKYFORGE

**Own the machine. Enter the battlefield.**

SKYFORGE is a browser-based helicopter combat game built around fast arcade combat, progression, player-owned assets, and a Solana-powered economy.

## MVP
- Third-person/top-down helicopter combat prototype
- Enemy drones and ground targets
- Weapon firing, health, score and missions
- Mobile-friendly browser controls
- Solana wallet connection foundation
- $SKY holder access gate (20,000 $SKY)
- Leaderboard/economy architecture ready for backend integration

## Architecture
- Next.js + TypeScript
- Phaser 3 for the first browser combat prototype
- Solana wallet integration
- Server-authoritative scoring/rewards planned
- On-chain ownership/marketplace planned; real-time combat stays off-chain

## Development
```bash
npm install
npm run dev
```
